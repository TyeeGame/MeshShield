Gateway decisions

Approved senders share slot 1; unauthorized senders share slot 2. Message rate limits and quarantine are separate from the virtual-device dashboard.

This protects this message service, not all laptop network traffic. The Argon receives the text and checks a shared bearer code; it does not inspect meaning or authenticate laptop identity. The trusted host provisions the code and delivers approved text. Demo HTTP traffic is unencrypted: use disposable messages and codes on a trusted demo network. Learned detection remains in the virtual-device dashboard.
